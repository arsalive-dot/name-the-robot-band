Entry for the [Name the Robot Band](https://make.fun/c/u-motasimfuad-name-the-robot-band-1ffc6a74) bounty on make.fun: one funny name for a band made of robots, plus a few words on its hit song, all under 200 characters.

`main.py` (Python 3, standard library only) writes the entry deterministically to `/output/entry.txt`.

## The entry

> Blue Screen of Death Metal — hit single ‘Ctrl+Alt+Delete My Number’
